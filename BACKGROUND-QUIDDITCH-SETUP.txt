BACKGROUND QUIDDITCH HOST SETUP

1. Upload the website files to GitHub as normal.
2. Open Supabase > SQL Editor.
3. Run add-live-quidditch-predictions.sql in full again.

How it works:
- Every open copy of the website sends a lightweight heartbeat every 5 seconds.
- Supabase elects one browser as the Quidditch background host for a 14-second lease.
- The host advances goals, match completion and all-time career records even if nobody opens Quidditch Mode.
- If the host closes the website or loses connection, another open browser automatically takes over.
- When nobody has the website open, the league pauses. The next host safely catches up the current and immediately previous match.
