REPO COMPANY — REPOGGLE + HARMONY LEADERBOARD FIX
=================================================

1. Extract this ZIP into the main RepoCompany website folder (the folder that
   contains index.html) and allow script.js / repoggle-migration.sql to overwrite.

2. In Supabase, open SQL Editor and run the ENTIRE file:

   fix-repoggle-and-harmony-leaderboards.sql

   This is additive and does not delete existing accounts, GP, XP or progress.

3. Commit/push the replaced files to GitHub main. Cloudflare will deploy them
   automatically.

4. Hard refresh the Cloudflare website with Ctrl + F5.

5. Repoggle: on the result screen that currently says REWARD SAVE FAILED, press
   RETRY REWARD SAVE after the SQL has completed. The level reward remains
   protected so it can only be granted once.

6. Harmonize: future signed-in +3 XP clicks are credited to the clicking player
   on both the daily XP leaderboard and global XP leaderboard. Both boards refresh
   immediately after a successful click. Historical Harmonize clicks cannot be
   assigned to individual users because the old system only stored one shared total.
