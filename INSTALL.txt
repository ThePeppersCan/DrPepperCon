REPOCOMPANY — RUNECRAFTING BUTTON + SHOOTING STAR UPGRADE

1. Extract this ZIP into the website root (the folder containing index.html).
2. Allow index.html, script.js and style.css to overwrite.
3. In Supabase → SQL Editor, run the complete file:
   update-shooting-star-3800-gp.sql
4. Commit and push the replaced/new files to GitHub main.
5. Wait for Cloudflare Pages to deploy, then hard-refresh with Ctrl+F5.

Changes:
- Repoggle and Runecrafting Pool mode buttons now use exactly matching dimensions.
- Rune Pool artwork is constrained so it no longer stretches the card.
- Shooting Stars has a new cinematic volcanic-night scene, layered starfield,
  meteors, impact glow, improved star, HUD, controls, miners and responsive layout.

Run the SQL file to change the actual server-side GP reward. Replacing only the
