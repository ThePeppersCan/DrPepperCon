ABYSSAL PROTECTOR PET — INSTALL

1. Extract this ZIP over the RepoCompany website root.
2. Allow script.js to overwrite and assets/pets/abyssal_protector.png to be added.
3. In Supabase > SQL Editor, run add-abyssal-protector-pet.sql once.
4. Commit/push the changed files to GitHub. Cloudflare Pages will deploy automatically.
5. Hard refresh the website (Ctrl+F5).

RESULT
- Abyssal protector appears in the Grand Exchange for 20,000 GP.
- It can only be purchased once per account.
- It enters the Bank as a normal pet.
- It can be named, let out/put away, shown in Pet Room/Quidditch and used by systems that read PET_CATALOG/active_pet.
- Existing pet cosmetics use the same generic pet rendering system.
