- Also remains available in Repoggle and Repo Rooftops game screens.
- It is a read-only mirror and does NOT call/open Quidditch spectator mode,

Wise Old Man:
- Any legitimate XP that reaches the canonical character skill total counts.
- Runecrafting: Repoggle + Rune Pool + all other RC XP sources.
