REPOGGLE — INSTALLATION AND TESTING
====================================

WHAT THIS PATCH DOES
--------------------
• Completely removes Rune Reactor from the website interface and Runecrafting mode selection.
• Adds Repoggle as a full 50-level Runecrafting campaign.
• Keeps the existing Rune Pool minigame available.
• Adds secure, one-time GP and Runecrafting XP rewards through Supabase.

INSTALL
-------
1. Make a backup of your current deployed website.
2. Extract this ZIP over the folder that contains your existing "web2" folder.
3. Allow the new files to replace matching files.
4. Run DELETE-OLD-RUNE-REACTOR-FILES.bat once from inside web2.
   • macOS/Linux: run "sh delete-old-rune-reactor-files.sh" instead.
5. In Supabase, open SQL Editor and run repoggle-migration.sql once.
6. If the Rune Reactor SQL was previously installed, run
   REMOVE-RUNE-REACTOR-DATABASE.sql once as well.
7. Deploy the updated files and hard-refresh the website (Ctrl+F5).

IMPORTANT
---------
• Do not run old rune-reactor.sql again.
• repoggle-migration.sql is additive and does not replace existing profile,
  character, gold or skill tables.
• Gold and Runecrafting XP are calculated in the database. The browser does
  not submit reward amounts.
• Logged-out visitors can play using local progress, but database rewards and
  shared leaderboard records require an authenticated account.
• Existing Rune Reactor database data is removed only by the clearly named
  REMOVE-RUNE-REACTOR-DATABASE.sql cleanup file.
