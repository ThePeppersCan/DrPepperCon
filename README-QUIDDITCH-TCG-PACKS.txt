REPO COMPANY — QUIDDITCH TCG PACKS

1. Run web2/quidditch-tcg-packs.sql once in the Supabase SQL Editor.
2. Replace your current web2/script.js with the included file.
3. Copy web2/assets/quidditch-tcg/ into the matching website assets folder.
4. Hard refresh the site with Ctrl + F5.

FEATURES
- Quidditch TCG Card Packs appear in the Grand Exchange for 60,000 GP each.
- Purchased packs are stored in the Bank and can be opened from there.
- Pack opening has a shake, card-back suspense, flip reveal, sound and XP rewards.
- Every pack guarantees a currently unowned card. Duplicate cards cannot occur.
- Each pack awards 5,000 XP and 10,000 XP to two different random skills.
- Unlocked cards are stored permanently and displayed inside the transparent binder slots.
- Player profile cards opened from leaderboards now include a View Binder button.
- Complete the Collection updates once all nine current cards are owned.
