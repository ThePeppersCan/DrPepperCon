FULLSCREEN QUIDDITCH MODE

While the Quidditch pet room is active, click QUIDDITCH MODE beside SKIP.

- Uses all currently live pets.
- Splits them into two balanced random teams.
- Random team names are selected for every three-minute match.
- Pet names (not account names) are shown as goal scorers.
- Matches continue endlessly until the fullscreen mode is closed.
- The supplied crowd audio loops quietly while the mode is open.
- Scores and scorer lists reset for every new three-minute game.
